# R10 经历记忆合同

新-only（N-MEMORY）；方向与未决项以[执行规划](../../../docs/rebuild-plan.md)
第 7 节为准。

## 写入与同意

- `write(consent, e)`：consent=false → `E_PERM`——**采集≠记忆**（采集
  面的同意是采集面的事；进入记忆须独立显式同意）。载荷 ≤128B、len>0。
- 来源（source_kind）随条目保存——衍生面可追溯建议/观测（R01 语义）。

## 有界与让位

- 链容量 64（建议值）；满=**最旧让位+evicted 计数**（不拒写——
  经历连续性优先于旧条目；让位可观）。

## 删除（tombstone）

- `delete(from,to)`：区间墓碑；读取跳过该区间——**删除后衍生面不
  复活**（后续同区间再写的新条目不受旧墓碑影响——按时间戳判）。
- 删除不可逆（不撤回已删除——R0 语义）。

## 恢复一致性

- RAM 后端=进程内链（机制验证）；持久后端（断电恢复/巩固事务）
  随板级批（R03 存储端口消费）。链序=写入序（t_ms 单调由调用方
  时钟保证——R01 时钟合同）。

## 持久面（板级批 A-4 注记）

板级批已交付存储挂载端口（flash 后端+真机持久化闸，见 r03-validation
板级批节）。**经历库持久 schema 未定**：链 64×~136B 超 KV 单槽上限，
需巩固/压缩/满盘处置设计=**D06 决策项**（owner）——机制端口就绪，
schema 定案后接入（不擅自定格式）。

## 未测与边界

持久化/断电恢复/巩固（板级批）；D06/D07 最低特性与后端成本比较
（真机批——MCU 日志 vs 索引）；跨设备同步（不在 R10 面）。
