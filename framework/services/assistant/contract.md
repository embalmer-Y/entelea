# R08 最小辅助闭环合同

新-only（N-CONTEXT/N-DELIBERATION）；方向与未决项以
[执行规划](../../../docs/rebuild-plan.md)第 7 节为准。

## 上下文汇聚

- 有界窗（16 条建议值）；窗满**弃最旧+dropped 计数**（不阻塞发布方、
  不无界增长）。快照只读（观测面）。事件 payload 借用发布方生存期
  （R02 事件合同——静态存储约束）。

## 触发

- 建议值：**窗满或显式**触发（无内部定时器——确定性；周期触发随
  D08 真机校准）。`should_deliberate` 为纯判定（无副作用）。

## 候选（模型=建议者）

- 结构化候选：kind（NONE/OUTPUT/TASK/NOTIFY）+ 人读 text + 来源
  （source=MODEL——建议非观测）+ 目标/值。
- **模型不能自批**：候选必须经 R04 principal 裁决（E_PERM 可观测
  拒绝）+ R02 保护层写路径。调用方必须从可信宿主取得 principal；
  公开 C 字段并不构成同地址空间的防伪或隔离保证。

## 执行门

- OUTPUT：权限门（按目标描述符类/实例 write 裁决）→ 类匹配（value_kind
  0/1/2 = GPIO/PWM/POWER）→ 写**已裁决描述符的 `safety_uid`**（不按候选
  逻辑名提交——同名他人通道不可越权写，RF1 P1-2）；POWER 经
  `entelea_power_request`，其余经 `entelea_safety_commit`
  （限幅/slew/锁存/审计全链复用——本层零旁路）。
- TASK：R04 任务面（上层组装——本层不重复受理逻辑）。
- NOTIFY：无副作用（无执行回执面）。

## 云依赖（D08）

- `assistant_available` = model UP 且 network UP（云模型经网络到达）。
  不可用 → 停用智能（上层据此停触发）；**独立 App 照常**（各自查
  各自依赖——R06 独立判定面）。不伪造本地离线智能。

## 模型适配层（B-2 已交付）

- 策略层（框架）：`entelea_model_ask`——依赖联动（模型+网络任一
  未 UP=E_STATE 且**不触传输**，D08）；仅传输明确返回 `E_NOT_SENT`
  （保证应用请求未发送）时有界重试，封顶 `ENTELEA_MODEL_RETRIES=2`。
  `E_IO`/`E_TIMEOUT` 可能发生在 POST 之后，绝不自动重试。
  用量是传输提供的累计下界，未知值不能当作零成本证明，计数饱和
  不回绕；输出缓冲下限
  （ENTELEA_MODEL_OUT_MIN=64——推理模型实测先耗 reasoning tokens，
  过小必截断）。失败尝试若传输报用量亦计入（成本如实）；依赖门
  逐尝试重查（重试中途 DOWN=E_STATE 停触传输）。D12 闸同样逐尝试
  （RF1 G5）：每次传输尝试均计入 D12（即使确定未发送也保守计数），
  重试被闸拒即停并返回闸结果——3 次连续失败即闩风暴且 MODEL DOWN，
  须外部 `entelea_guard_storm_clear` 释放；鉴权失败也立即 MODEL DOWN。
- 显式 `entelea_model_probe` 在网络 UP、D12 允许时可探测尚未恢复的
  MODEL，避免“需先 UP 才能验证 UP”的循环；它不自动修改恢复状态，
  调用方只可据每次真实结果分别上报，不能把一次成功伪报成两次。
  模型调用由调用方串行化；D12 状态由互斥端口串行化（未绑定即拒绝）。
- 传输层=可插拔 ops（mock 测试闭环；真传输随真网批/SDK 批接入同一
  形状——框架不含网络栈/TLS，无新依赖）。主机真调用冒烟：
  tools/model_smoke.py（凭据在工作区外，台账逐笔记）。
- 当前 Linux/Zephyr HTTPS 诊断传输只接受一条 user 消息；成功需有效
  HTTP 分帧和 `choices[0].message.content`。无长度的关闭定界响应
  还需 TLS close-notify；原始 EOF 不等于认证关闭。响应压缩和不支持
  的传输编码明确拒绝，服务商兼容性不能由离线桩证明。
- 同一调用从开始共享时间预算并在各阶段返回前后检查，但同步 DNS、
  连接及 TLS 后端内部调用仍可能阻塞，**不保证端到端硬截止**。
  临时 HTTP 请求/响应缓冲在成功和失败时清除；调用方仍负责自己的
  凭据、副本及输出生命周期，不能据此声称所有平台内存均已清除。
- 云/WiFi 诊断失败只停用相应依赖并退出诊断，不把普通网络或模型
  失败升级为硬件安全故障；启动与监督故障仍按安全合同处理。
  两次模型恢复探测加一次正常调用会产生至少三次实际模型请求，
  且明确未发送时可能重试；实际运行需要独立授权并可能产生费用。

## 未测与边界

真实模型调用/延迟/恶意输出矩阵（真机+云批）；周期触发阈值（D08）；
多轮对话/记忆整合（R10 经历面）；模型超时（D08 真机）。
