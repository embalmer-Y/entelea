# Galatea 产品与研究边界

本文说明 Galatea 如何成为 Entelea 上的渐进产品，而不是第二套设备系统。
功能需求和完成状态只在[项目功能需求与总进度](requirements.md)维护；
运行职责见[架构](architecture.md)，固定来源见[迁移出处](provenance.md)。

## 产品定位

首版目标是具备持续情感状态、有限自身状态认知、可取消任务和受约束主动
交互的具身 AI 个体。它复用通用框架的能力、任务、上下文和输出保护，
不通过人格提示词代替真实状态，也不要求普通任务设备具有陪伴驱力。
当前合并是产品主线、合同和可复用验证资产的合并，不提前宣称设备闭环。

首批硬件仍为已确认的 P4/C5 套件。模型推理可在设备、边缘或云端，常驻
上下文、候选校验与任务管理仍在设备。Forge 只制造和受控交付能力，
不是运行时大脑，也不自动拥有模型晋升或安全变更的审批权。

## 研究模块到产品模块的映射

下表是职责映射，不是研究代码已移植或产品已验收的清单。

| Galatea 研究模块 | Entelea 的承接位置与范围 |
| --- | --- |
| L00 内核 | 复用 Zephyr 时间、事件、调度和状态所有权；不复制 Python 调度器 |
| L01 世界与通道 | MW0 留在研究仓库；产品使用真实驱动与带来源的输入 |
| L02 感觉、L03 知觉 | P10 输入整理与有界上下文，P13 模型理解；区分观测和推断 |
| L04 身体与自我模型 | P07/P08/P12 的能力、任务、故障及回执派生视图 |
| L05 驱力与情感 | 复用 `lib/affect/`；P11 接入单写者、快照及启用/禁用 |
| L06 记忆 | 首版仅 P10 易失上下文；长期记忆不在当前启用范围 |
| L07 工作空间 | P12 有限候选与受预算约束的决策，不声称全局访问意识成立 |
| L08 动机、L09 元控制 | P12 任务采纳、取消、观察和求助；P14 主动候选守门 |
| L10 行动与归属 | P07/P08 权限、通道所有权和观测回执，保留现有安全提交 |
| L11 学习与巩固 | 当前不启用；后续候选版本、独立验证和回滚须另行定合同 |
| L12 语言与社会 | P13/P14 真实语音、结构化模型结果和有界表达 |
| L13 独立证据 | 研究评价留在原仓库；产品维护适用回归、对照与实际硬件证据 |

Entelea 的 P04 是硬件独立验证节点，P06 承接产品能力与联动；
Galatea 的 P4-α/β/γ/δ 是预测脑研究阶段。
两套编号没有进度换算关系；原仓库的测试数量和研究结论不计入产品验收。

## 保留与暂不启用

原 Galatea 仓库及固定研究基线保持不变，保留 MW0、Python/PyTorch、
原始实验、独立评价、历史 ADR 和证据谱系。本仓库不复制研究文档体系，
不迁入原始媒体、会话、凭据、模型权重或证据目录。

长期记忆、跨重启认知身份、跨设备身份连续、通用预测脑、在线权重学习、
做梦巩固和完整科学能力认证属于后续方向，不是当前首版验收项。启用前须
确认数据保存/删除、授权、资源、模型版本、保护集与回滚；不得借产品合并
自动扩大已有数据边界或改写安全合同。

## 可复用验证资产

[情感参考](../lib/affect/tests/reference/galatea.py)保留原 Galatea 的低通、
迟滞、饱和和效价计算，用于生成独立数值参照。
[C 回归](../lib/affect/tests/galatea_reference.c)直接执行现有内核并比较
共享算子的行为，普通 `make check` 不依赖原研究仓库或 PyTorch。

参照限定于共享数值语义；社交驱力、`social_bond`、伦理闩锁、表达标签和
重评价产品差异不能据此宣称与完整 Galatea 同构。P11/P14 仍须验证真实
输入、下游影响、禁用对照及用户干预，不能把数值一致当作功能性感受证明。

## 后续协作方式

- 产品开发和需求更新集中于 Entelea，按[调整后的阶段范围](requirements.md#2026-11-06-开发阶段调整)
  先进行 P05 工程重整、P06 硬件深化，再由 P07–P14 承接原产品关卡。
- 研究成果进入产品前固定来源和许可，明确假设与差异，迁入适用回归；
  移植必须重新验证，不搬运旧结论作为新设备的完成证明。
- 合法用户任务与主动候选共用校验和执行链；主动候选不能以陪伴需求
  阻断合法任务或绕过用户取消。具体优先级与争用在 P07/P12 冻结并测试。
- 每个模块同步对应需求编号、实际验证、未覆盖范围和需要用户决策的事项，
  不新增第二份总进度表。长期方向未获批准前不自动进入产品默认值。
