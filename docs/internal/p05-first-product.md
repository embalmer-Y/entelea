# P05 首个验收产品定义：智能伴侣

讨论时间：2026-11-07（UTC+8）；18:59 按用户要求拆分。
本文仅定义首个智能伴侣产品的目标、场景、硬件和验收范围。
框架机制及合同以[框架层定义](p05-framework.md)为准，
实现进度以[唯一需求表](../requirements.md)为准。
“伴侣”不是模拟智能的同义词，不将本文配置推广到全部模拟智能设备。

**状态：首期目标、最小场景、非目标和产品验收方向已确认；
具体型号、数值、界面及依赖框架的细节待设计。未开始实现。**
本轮不冻结所有详细合同，不表示功能已验收或扩大数据/硬件授权。

## 1. 首期交付目标

**已确认：完成基于 Entelea 的桌面 AI 伴侣及其框架支撑能力。**
原 Kaleido 是产品愿景和资产来源，不恢复为并列框架，不提前决定
最终名称，不自动继承所有旧设想或补完全部历史 backlog。
追求统一、可恢复、可长期使用的产品，不是多个独立诊断工程。

框架通用性另由[辅助智能参考配置](p05-framework.md)验证，
不在这里新建第二个完整消费产品；两种配置复用公共合同和适用实现。
伴侣属于模拟智能参考产品，首期只控制自身外设，跨设备控制后续实现。
首期不同时交付完整 Linux 认知产品，也不要求先完成所有芯片支持。
P05 是讨论、治理与后续设计，不表示本阶段完成全部产品开发。

框架提供能力/生命周期/依赖/授权机制；伴侣提供角色、场景、UI 和
装配策略。例如显示接口不等于角色全屏舞台，模型合同不绑定特定
云服务，记忆机制不自动决定保存内容。产品不绕过框架写专用捷径。

## 2. 已有资产与证据边界

当前参考板为 `68007`，底板 V1.5，P4/C5，具体组合还需核验。
P04 独立验证过显示、有限触摸、声学正反对照、SD 文件读写及独立
IDF SC2336 成像；不等于正式 Zephyr 驱动、媒体联合负载、音质/画质、
长时或完整 App 生命周期通过。音频使用隔离候选补丁，当前 C5
固件/网络未独立完成验证，不能继承旧板 `67689` 的证据。
详细限制见[测试记录](../testing.md)，本文件不复制硬件实验流水。
原 Kaleido 的语音、情感、表达、记忆及 HIL 资产作复用参考，
其历史性能和测试绿色不算当前框架或当前板完成。

## 3. 五个必需用户场景（12:10 已确认）

| 场景 | 产品结果与验收边界 |
| --- | --- |
| 首次配置与日常设置 | 配网、模型配置、音量/亮度、静音和关闭自主交互；失败明确提示，配置重启恢复，凭据不进日志 |
| 自然对话与打断 | 唤醒或触摸开始、连续追问、结束及随时停止；实际停止播放、迟到响应不重新开口、模型失败不伪装成功 |
| 连续状态的交互 | 情感/驱力、近期互动及记忆实际影响表达；不由 LLM 随意直写情感，关闭情感仍可执行合法任务 |
| 一个完整任务 | 创建、查询、修改、取消和结果反馈；取消后不再触发，重启语义明确 |
| 条件触发的自主思考与受控行动 | 根据当前情境、记忆、情感和任务决策；思考与执行许可分离，保持安静也是有效结果 |

计时和到期提醒是完整任务的候选例子，具体代表任务待选。
已安装的本地任务不因云端离线全停，按实际 App 依赖和框架安全合同
判断；持续需要云端算力的任务停用，不能套用旧“离线分析继续”建议。
勿扰、静音、冷却、用户正在说话以及拒绝/关闭在适当环节有效。
触发慢思考不自动授权采集或上传媒体。

## 4. 记忆与经历相关的性格

### 已确认

- 经历记忆是产品核心，不仅保存少量偏好；积累、巩固、遗忘与检索
  应实际影响评价和行为。参考 Galatea 研究，引入 LLM 定期优化，
  详细架构后续设计，不宣称模拟等同真实人脑。
- **强制大于 8 GB 的 TF 卡**，8 GB 不满足；常见最低标称档为 16 GB，
  可用空间、卡品质和文件系统待定，不把 TF 容量变成所有框架最低要求。
  启用经历记忆的其他配置也遵守已确认的存储要求；辅助智能可不需要。
- 缺卡或记忆不可恢复时暂停正常伴侣运行，只保留安全、设置与修复
  入口；不自动格式化、创建空白角色或进入无记忆临时模式。
- 稳定性格倾向通过重复经历缓慢形成，允许数个月甚至更久；
  不要求短期显著变化。短期情绪与长期倾向分离，不由单次事件改写。
- 矛盾经历可按情境共存，不强制永久标签；成长解释须有经历依据，
  不由 LLM 事后编故事。“数个月”不是到期必须改变，
  无相关经历不能仅凭运行时长改变性格。
- 首期验证机制贡献与重启连续性，真实长期发展持续观察；
  加速重放不冒充数个月实际运行。
- 不自动授权原始媒体、完整会话保存或记忆云端外发；性格适应
  不改变核心角色约束、安全、权限或信任根，不要求在线权重学习。

### 功能建议，尚未逐项确认

选择性记忆、来源/可靠度、情境关联、情感与记忆双向作用、
巩固概括、遗忘和纠错、跨重启连续性、记忆健康状态。
用户入口建议包括查看、纠正、删除、“请记住”和“这次不要记住”。
不把强情感当事实可靠度，不把认知遗忘当用户删除。
技能经验、自传性组织、备份和迁移可后续增加，避免虚构人生或
备份恢复复活已删除内容。
这些建议不全部视为用户已批准的首期功能；详细机制参见框架待设计项。
只读、空间满、写入失败等不同于缺卡/不可恢复，其产品处置待定。

## 5. 新能力开发与用户验收（已确认首期必需）

**用户需求 → AI 开发 → 工程验证 → 受控试用 →
用户验证并确认 → 正式安装/启用。**

产品必须提供需求提交、进度/失败说明、试用、拒绝/修改、明确确认
和停止/撤销的可操作流程，不以手工打包安装演示代替完整闭环。
具体交互入口、权限提示、试用期限和失败恢复 UI 待框架完善后设计。
确认针对具体候选内容和权限；修改后重新工程验证和试用；
健康绿灯不代替用户验收，用户满意不豁免框架安全检查。
试用不是正式常驻，失败保留可用版本；数据晋升/隔离由框架合同决定。

“专注/休息助手”是候选代表 App，尚未选定。首期不建设完整商店，
不要求 MCU 本地编译，也不允许智脑直接修改固件。

### 产品交付体验（19:09 接受建议，界面细节待设计）

1. 自然语言提出需求，歧义时澄清并说明能力限制。
2. 展示简短方案、权限/服务依赖和验证方法，用户批准开发。
3. 呈现真实开发/验证/失败状态并允许取消，不编造进度。
4. 展示候选和试用范围，用户明确同意后受控试用。
5. 提供简单可观察的操作让用户验证，不要求阅读工程日志。
6. 用户反馈修改或拒绝，停止试用；修改后重新验证和试用。
7. 用户确认当前候选后正式安装/启用，说明启动方式和依赖。
8. 提供版本/状态、停止、卸载和按合同恢复可用版本的入口。

需求、批准、确认入口及试用期限待设计，不建设完整商店。
**框架开发例外不改变本产品合同：**显式开发/测试配置可以直接部署
候选和提高有界预算，但不能用这种路径冒充正式产品用户验收。
正式安装不等于自动启动；具体运行行为必须向用户说明并符合合同。

## 6. 产品硬件建议（18:59 接受方向，待定项保留）

| 类别 | 首期产品建议与状态 |
| --- | --- |
| 主控/网络 | 沿用当前 P4/C5，固定板/硅/固件组合；具体组合待核验 |
| 显示/触摸 | 主要表达、操作与本地停止入口；型号、布局待定 |
| 麦克风/扬声器 | 语音对话及表达；音质、距离、音量范围待定 |
| TF | 大于 8 GB 已确认必需；品质、文件系统和剩余空间门槛待定 |
| 摄像头 | 明确触发的单帧视觉扩展；是否首期必交付待定 |
| 运动机构/配件 | 不纳入首期必需；不因框架有输出接口增加机构 |
| 蓝牙播放 | 仅离线策略的音响产品例子，不自动纳入本产品 |

硬件类别用于本产品验收，不约束所有模拟智能设备。
不擅自新增采购、刷机、硬件操作或付费调用。

### 视觉与语音待定边界

19:27 确认媒体合同位于[可选框架扩展](p05-framework.md)，
本节仅定义智能伴侣的具体场景与体验。框架支持接口不自动使摄像头、
AEC 或全双工成为本产品首期必交付；平台驱动和算法另行设计。

单帧视觉场景为“明确触发 → 新帧/采集时间 → 推理 → 返回 → 释放”。
必须处理取消、采集失败、超时和迟到结果；不持续监视、上传或默认
人脸识别。图像文本不自动成为指令。此场景为扩展，不是通用最低能力。

可靠打断必需：本地触摸/操作停止不能等待云端；还须清理待播数据、
取消请求及拒绝迟到输出。播放中识别人声的语音打断、AEC、边播边听
是独立体验合同，尚未冻结是否首期必交付；完整消费级全双工非首期目标。
后续上下文不能把未播放部分当用户已经听到。
原 Kaleido AEC 回退经验及厂商新算法需实机复验，不拿回声降低或
厂商 P4 频率/缓存条件下吞吐当真人打断通过。

## 7. 异常状态的产品表现（方向已确认，UI 待设计）

| 状态 | 产品表现原则 |
| --- | --- |
| 待配网 | 网络未配置/失效，有明确修复入口 |
| 智能服务不可用 | 网络正常而云端不可用，停止智能，不误导用户重新配网 |
| 记忆不可用 | 按缺卡/不可恢复规则暂停正常伴侣，不自动新建角色 |
| 某能力不可用 | 按该 App 依赖处置，不等同整台产品故障 |
| 试用/更新失败 | 告知候选状态及恢复操作，不冒充已正式安装 |

固定功能按声明依赖继续，安全和停止独立有效；本产品具体固定功能
清单待定，不假定音响例子就是伴侣默认功能。
云端恢复但记忆仍不可恢复时，不启动正常伴侣。
日志有界保存，授权后供恢复分析，不默认上传全部数据。
界面能提供基本本地故障说明，不依赖云端生成提示；
恢复和状态映射按框架合同，不另写旁路。

## 8. 产品验收维度（方向已确认，数值待定）

| 维度 | 状态 |
| --- | --- |
| 用户说完至有效回答首音 | 保留既有 P95 ≤ 1.5 秒目标，端点/样本/网络/并发负载方法待冻结，提示音或首包不算 |
| 本地停止至实际输出停止 | 实测，阈值待定 |
| 真人唤醒与误唤醒 | 距离、环境、播放音量、样本数及通过率待定 |
| 对话/表达/记忆/App 联合运行 | 实测并发、资源峰值和依赖变化，上限待定 |
| 长时运行 | 资源不持续泄漏，异常可恢复；24/72 小时只是候选测试阶段，不是已批准时长 |
| 网络/重启/掉电/存储故障 | 按框架合同验证真实产品表现，不继承其他板证据 |
| TF 与记忆维护 | 验证写入/巩固延迟及交互影响，预算待定 |

不能等测试结果出现后随意放宽阈值。没有机构或观测的物理项目明确
不适用，不虚构急停/运动通过。独立外设通过不是联合使用通过。
产品完成度、框架支撑度、辅助智能通用性分开验收。

用户控制方向已接受：静音、停止、关闭自主交互、查看状态、试用确认/
拒绝/撤销和失败恢复入口。记忆管理具体 features 仍待逐项确认。
云端优化/诊断外发有说明与授权，首次配网不等于永久批准所有外发。

## 9. 首期非目标（已确认）

- 完整脑、智慧生命或意识证明。
- 在线权重学习、做梦巩固、跨设备身份连续；定期记忆优化不等于这些。
- 跨设备控制、多设备管理、编队或分布式任务。
- App 商店、开放生态、任意配件即插即用。
- 无限记忆、默认保存或上传原始媒体。
- 全厂商/全芯片/任意模块组合。
- 无校准依据的剩余寿命预测。
- 同时交付完整 Linux 认知产品。
- 完整消费级全双工；不借此取消可靠打断要求。
